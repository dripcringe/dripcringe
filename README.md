<h3 align="center">Powered by curiosity (and too much coffee).</h3>

I build frontend interfaces for a living and spend an unreasonable amount of time second-guessing my own component APIs. Lately I've been drawn to the quieter problems: how a page loads, how a design system ages, whether a button actually makes sense to someone using a screen reader. I work mostly in TypeScript, React, Next.js, and Tailwind, and I've grown fond of Vite for how little it gets in the way.

#### What I'm up to

- 🔭 A component library that tries to make accessibility the default, not the afterthought.
- 🛠️ Tinkering with side projects on weekends
- ☕ Powered by coffee and late-night commits
- 🚀 Interested in design systems
- 💬 Ask me about React
